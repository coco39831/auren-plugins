# 語音轉文字插件

這是可選安裝的短語音轉寫功能。可使用麥克風錄音或選擇 WAV、MP3、M4A、MP4、OGG、FLAC、WebM 檔案，取得文字後可編輯、複製及下載；不會自動送出聊天訊息。

首次請進入本插件設定，填寫 OpenAI 相容音訊轉寫 API 的基底位址（例如 https://api.openai.com/v1）、實際支援的模型與 API 金鑰。本機服務可填 http://127.0.0.1:連接埠/v1；支援聊天的服務不一定支援音訊轉寫。語言留白為自動判斷，也可填 zh、en、ja、ko。

外部轉寫需要使用者明確同意；每次送出的只有使用者選擇或錄製的音訊。本機連線不等於其後端一定不連外，請自行確認服務設定。金鑰加密保存在目前 Agent 的插件資料目錄，不經插件公開設定回傳。音訊與逐字稿不另行保存，關閉畫面會清除；稽核只記錄大小與操作種類。

單次音訊上限 700 KiB，適用短句與分段輸入。錄音最長 45 秒；麥克風需瀏覽器支援並授權，跨裝置須 HTTPS，不支援時仍可選檔。基本安裝不下載模型或安裝其他環境。

介面及後端都需要已安裝並啟用本插件。安裝不影響其他聊天；尚未設定時會引導連線，不能把未連線當成已完成轉寫。移除插件保留加密設定，重新安裝可沿用。

規格來源：https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create
